# ЭРА Android — v0.6.0 (build 6)

Python + Flet 1.0.5. Работает с общей базой сайта `эра-новая.рф` через FastAPI `/api/mobile/v1/*`.

### Экраны

Главная/статистика; авторизация и запоминание входа; профиль, аватар и пароль; пользователи и чат с вложениями; новости/лайки/комментарии; внешние новости; календарь; расходы и категории; магазин и покупки; шрифты чата; управление новостями для администраторов; проверка обновлений.

### Windows (PyCharm)

1. Запустите `install_windows.bat` один раз, если нет `.venv`.
2. Запустите `run_windows.bat`.
3. Для APK: `build_apk_windows.bat` (ключ подписи должен совпадать с v0.5).
4. Версии уже выставлены в `pyproject.toml` / `src/update_config.py`.

### Сервер

Сначала установить на Beget `server/era_mobile_api.py` и `server/era_mobile_features.py` из полного комплекта, иначе новые экраны получат HTTP 404.

### Безопасность

Никогда не выкладывайте `.env`, `signing.local.bat`, ключи `.jks/.keystore` и базы пользователей в Git. Старые прототипные локальные SQLite-файлы не используются для авторизации ЭРА и не мигрируются на сервер автоматически.
